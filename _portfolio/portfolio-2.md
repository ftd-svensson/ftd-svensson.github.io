Tinker Tails is a fast-paced multiplayer team action game about building airships. The whole program was built from scratch in 14 weeks and served as our final game project before our thesis.
For this project, we worked in a team of 12 developers, simulating a SCRUM work environment while building the entire game engine and game logic from scratch.

My main area of contribution to this project was the integration of the Wwise audio solution into our game engine. This involved adapting Wwise to work within our existing engine architecture and scripting system, as well as setting up the necessary communication between the engine and the Wwise application to allow for audio editing and iteration. I also worked on integrating the audio system with ENTT, ensuring that it could function effectively within our entity-component architecture and interact with the rest of the game systems.
